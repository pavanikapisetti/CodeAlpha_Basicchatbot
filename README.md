# Basic Chatbot 🤖

## About the Project
Basic Chatbot is a simple rule-based chatbot developed using Python. It interacts with users through text input and provides responses to common messages such as greetings, questions about its name, and requests for help.

## Features
- Responds to greetings such as `hi`, `hello`, and `hey`
- Answers the question "How are you?"
- Introduces itself when asked for its name
- Provides help with supported commands
- Exits the conversation when the user types `bye` or `exit`
- Converts user input to lowercase for easier matching

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal and run:

```bash
python chatbot.py
```

## Example Interaction

```text
You: Hello
Alphabot: Hello! How can I help you today?

You: How are you?
Alphabot: I am doing great! Thanks for asking.

You: Your name
Alphabot: My name is Alphabot, your virtual assistant.

You: Bye
Alphabot: Goodbye! Have a wonderful day!
```
